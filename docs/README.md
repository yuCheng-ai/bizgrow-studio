# BizGrow Studio 文档中心

本目录用于沉淀 BizGrow Studio 的产品、架构、DSL、运行时与 MVP 实现路线。

BizGrow Studio 的定位：

> 本体驱动的语义低代码业务运行系统。

它不是传统拖拽式低代码，也不是普通 BPM / OA / ERP。

核心链路：

```text
业务本体
→ 业务对象
→ 关系图谱
→ 状态机
→ 规则
→ Agent 边界
→ 业务闭环模板
→ 业务闭环实例
→ 任务中心
→ 审计日志
```

## 当前阶段

当前阶段不是做全行业通用平台，而是先打穿一个最小业务闭环：

```text
订单评审
→ 库存检查
→ 采购建议
→ 人工确认
→ 生产任务
```

这个闭环如果能真正跑起来，BizGrow Studio 就从概念原型进入产品内核阶段。
